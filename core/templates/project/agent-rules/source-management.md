# Source Management

Keep one canonical document per concern. Do not create multiple 'latest/final' duplicates. Retain dated historical snapshots.

Before editing: read the current canonical source, relevant project rules and changelog policy. Verify reference dependencies.

For create/edit/move/rename/retire/delete: update affected README, indexes, links and changelog in the same task. No unrequested deletion. A change is incomplete if any required supporting update fails.
